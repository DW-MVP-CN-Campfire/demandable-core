# Governance

Demandable Core is an early-stage open-source project covering AI-powered demand generation and Arbitrum escrow payments. This document describes, informally, how decisions get made.

## Roles

- **Maintainers** review and merge pull requests, cut releases, and steward the roadmap.
- **Contributors** are anyone who proposes changes, reports issues, or improves docs. See [CONTRIBUTING.md](CONTRIBUTING.md).

## Decision making

- Day-to-day changes are decided by pull request review; one maintainer approval is enough for routine changes.
- Significant architectural choices are recorded as ADRs in [docs/adr/](docs/adr/) and discussed in the PR before acceptance. We aim for consensus; if none emerges, maintainers decide.
- Changes touching escrow or fund-handling logic should get extra scrutiny and, once contracts exist, tests and review from more than one maintainer.

## Roadmap

Direction is tracked in [ROADMAP.md](ROADMAP.md). Anyone may propose changes through an issue or pull request.

## Conduct and security

All participants follow the [Code of Conduct](CODE_OF_CONDUCT.md). Vulnerabilities are reported privately per [SECURITY.md](SECURITY.md).

## Changing this document

Propose changes by pull request; maintainers approve them.
