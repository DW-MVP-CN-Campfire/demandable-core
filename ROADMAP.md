# Roadmap

Demandable Core is a hybrid: an AI-powered demand-generation platform with Web3 (Arbitrum) escrow payments. Items below are planned unless noted otherwise. See [ADR 0001](docs/adr/0001-hybrid-stack-and-arbitrum-mcp.md) for the stack decision.

## Phase 1

- Core framework
- API foundation (TypeScript/Node.js)
- Escrow contract foundation (Solidity, Foundry)
- Arbitrum MCP integration ([docs](docs/integrations/arbitrum-mcp.md))
- Documentation

## Phase 2

- AI agent orchestration
- Knowledge management
- Integrations
- Escrow-backed demand-generation engagements (fund, deliver, release)

## Phase 3

- Enterprise governance
- Marketplace
- Multi-tenant deployment
